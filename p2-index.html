P2 · LLM regression test harness

Does a new model or prompt version make the chatbot worse — and would we notice before release?

A versioned evaluation suite for a retrieval-augmented (RAG) chatbot. Every run records the model version, prompt and output, and a GenAIOps-style regression gate in CI fails the pipeline when quality falls.

What this project shows an employer

  • Evaluating non-deterministic systems
  • Hallucination and groundedness checks
  • GenAIOps: evaluation as a CI gate

Scope

System under test

A small RAG chatbot answering questions over a fixed document set

Test types

Deterministic checks, metamorphic tests, hallucination and groundedness checks, LLM-based judge

Pipeline

GitHub Actions runs the suite on every pull request
